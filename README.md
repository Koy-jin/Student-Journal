# Student Journal (Электронный студенческий журнал)

Клиент-серверное веб-приложение для ведения учёта успеваемости студентов, упакованное для развертывания в контейнерах с автоматизированным CI-пайплайном.

## Стек технологий
* **Backend:** Python (`app.py`, `db_worker.py`), REST API (Swagger-документация в `swagger_docks/`)
* **Frontend:** Vanilla JS, HTML5, CSS3 (`templates/`)
* **Database:** PostgreSQL (схема инициализации в `init.sql`)
* **Инфраструктура и CI/CD:** Docker, Docker Compose, Nginx (reverse proxy + раздача статики), GitHub Actions

## Архитектура 
Приложение разделено на изолированные сервисы внутри сети Docker Compose:
1. **Nginx (`Dockerfile.nginx`)** - точка входа: отдаёт статические файлы фронтенда и проксирует API-запросы к бэкенду.
2. **Backend** - приложение на Python, обрабатывает запросы к БД.
3. **PostgreSQL** - реляционная база данных с автоматической инициализацией таблиц через `init.sql` и сохранением данных в volume.
 
## Быстрый запуск (Docker Compose)

1. Клонируйте репозиторий и перейдите в директорию проекта.
2. Создайте файл `.env` с переменными окружения на основе шаблона `.env.example` 
3. Соберите и запустите контейнеры в фоновом режиме: 
```bash
docker compose up -d --build
```
4. После запуска приложение будет доступно в браузере по адресу `http://localhost:80` (или на порту, указанном в `docker-compose.yaml`)
